# Snake Water Gun Game 🐍💧🔫

A simple Snake Water Gun game made using Python.

## 📌 About the Project
This is a beginner-friendly Python mini project based on the classic Snake Water Gun game.  
The user plays against the computer, and the winner is decided based on the game rules.

## 🎮 Game Rules
- Snake drinks Water → Snake wins
- Water damages Gun → Water wins
- Gun kills Snake → Gun wins

If both choices are same, the match is a draw.

## 🛠️ Technologies Used
- Python
- VS Code
